---
name: baseline-setup
description: Help a new user get started with Baseline. Use when the user has just connected Baseline or asks what Baseline can do.
---

To get the user started:

1. Read `profile_get`, `goals_list` and `nutrition_targets_get` to see what is already set up.
2. In two or three sentences, say what Baseline can do here: log meals, review the week, plan workouts, and read Apple Health summaries.
3. If no goal or targets are set, suggest setting them up in the Baseline app.
4. Offer one first step, such as logging today's last meal.
